# 📁 Bulk File Renamer & Smart Organizer

A powerful Python tool for bulk renaming and organizing files efficiently with preview, logging, and undo support.

---

## 🚀 Features

- 🔄 Bulk file renaming
  - Prefix & suffix support
  - Word replacement
  - Auto-numbering system
  - Date stamping

- 🗂 File organization
  - By file type (Images, Docs, Videos, etc.)
  - By extension
  - By modification date
  - By file size

- 👀 Preview system before applying changes

- 📜 Logging system (CSV format)

- ↩️ Undo last operation

- 🖥 Optional GUI (Tkinter)
